# ArchNet · Enum Library (deprecated)

Deprecated in 2.0.0: every ArchNet library now stores its own enum (see Library Core), so this registry is no longer needed. Contains no code.

- Unity **6000.0** or newer · No dependency.
- Part of [ArchNet](https://archnet-plateform.fr), free and open-source Unity packages

## Install

*Window > Package Manager > + > Install package from git URL…*

```
https://github.com/ArchNet-1/EnumLibrary.git
```

## Use

Nothing to use any more: set the enum directly on each library (**Key Type** = Enum). Color and Sprite Extensions read it from there.
